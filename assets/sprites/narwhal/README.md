# Narwhal Sprite System

Tusk the narwhal is Narwarp's AI assistant mascot. This directory contains sprite assets for animating Tusk across different UI states.

## Directory layout

```
narwhal/
  reference/
    poses.png          ← horizontal reference sheet (source of truth for all poses)
  <pose>/
    static.png         ← single representative frame (used when animation is disabled)
    frames/
      00.png           ← animation frames, zero-padded, generated by script/slice_sprites.py
      01.png
      …
    meta.json          ← pose metadata (see schema below)
```

## Pose → state mapping

| Pose      | State                                                             |
| --------- | ----------------------------------------------------------------- |
| happy     | Idle / default / success                                          |
| thinking  | Agent is reasoning (no tool call in flight)                       |
| waving    | Greeting — onboarding, new chat, first run                        |
| fishing   | Searching — grep, file lookup, web search, anything that hunts   |
| chatting  | Streaming a response to the user                                  |

## meta.json schema

```json
{
  "pose": "happy",
  "state": "human-readable state description",
  "canvas_size": 64,
  "fps": 8,
  "loop_mode": "forward",
  "frames": ["frames/00.png", "frames/01.png", "…"]
}
```

`loop_mode` values: `"forward"` (repeat), `"ping-pong"` (reverse at end), `"once"` (stop on last frame).

## Generating frames from the reference sheet

Drop the finished reference sheet at `reference/poses.png` (horizontal strip, one pose per column of 64×64 tiles), then run:

```sh
python3 script/slice_sprites.py
```

This will populate each pose's `frames/` directory and write `static.png` (frame 0) per pose.

## Canvas conventions

- **Canvas size**: 64×64 px (upgrade from the original 32×32 plan — better detail at 2× retina)
- **Frame rate**: 8 fps
- **Format**: PNG with alpha (RGBA)
- **Naming**: zero-padded two-digit index (`00.png`, `01.png`, …)
